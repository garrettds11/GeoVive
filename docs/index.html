GeoVive Docs

Mapbox + OpenStreetMap starter for geospatial projects.

Overview

GeoVive is a small but opinionated starter for building interactive map dashboards with Mapbox GL JS and OpenStreetMap data. It shows how to:

  • Render a Mapbox basemap and swap styles at runtime.
  • Overlay custom point data (events, locations, alerts) as GeoJSON.
  • Drive the map from a sidebar with filters and feature lists.
  • Load datasets from static files, CSV, or live APIs (DynamoDB, etc.).

Getting Started

Local dev

From the project root:

python -m http.server 8000

Then open http://localhost:8000/index.html in your browser.

Mapbox setup

  • Create a public token in your Mapbox account.
  • Allow localhost during development (no URL restrictions, or include http://localhost:8000/*).
  • Paste the token into mapboxgl.accessToken in index.html.

Datasets

The dataset selector in the sidebar can switch between multiple sources:

  • Demo points – in-memory GeoJSON defined in geoviveData.
  • CSV – a simple CSV file parsed client-side into GeoJSON.
  • OSM GeoJSON – data exported from Overpass Turbo and stored as a static file.
  • DynamoDB (planned) – a FeatureCollection served by an AWS API.

CSV format

Expected headers:

name,category,lat,lng,description

AWS & Backend Integration

GeoVive is designed to plug into lightweight backends such as AWS Lambda + DynamoDB. A typical pattern is:

  1. DynamoDB table storing points with id, name, category, lat, lng, description.
  2. Lambda function that reads the table and returns a GeoJSON FeatureCollection.
  3. API Gateway route (e.g. GET /geovive) that the front-end calls from the "Dynamo" dataset option.

See the main repository README for up-to-date backend examples and deployment notes.
