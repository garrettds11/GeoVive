Principles

  • Neutral canvas. GeoVivé shows what connected businesses bring; it keeps no subject-matter layers of its own and never resells yours.
  • Nothing unreviewed goes live. Every new or changed layer is checked before users see it.
  • Least data, least access. Each part of the system can reach only what it needs, and sensitive values are kept out of logs.

Your data stays yours

  • Layers are shown only to your users, only inside GeoVivé, and are never listed for other apps, offered for download or used to train models.
  • Relay layers are kept as a simplified display copy for no more than 7 days; direct layers are never copied.
  • Cached copies are deleted within 7 days of a connection ending. Details are in the AppConnect terms.
  • Maps users make belong to those users. Private maps are visible only to their owner.
  • Account linking is always the user's choice. An app sees only maps it created for that user or that the user shared with it (read-only), never their email or GeoVivé account ID, and gets a user ID that's different for every app. Users can remove an app any time in My data, and access stops at once.

How layers are reviewed

  1. Domain proof. Only the business that controls a domain can connect layers from it.
  2. Automatic checks on every new or changed layer: public HTTPS sources only (private networks are blocked), valid shapes and coordinates, size limits, credits and license, browser access for direct layers, and field names and values that look like personal information.
  3. AI review of the layer's text (see below), when enabled.
  4. Human review of anything a person must judge, within 5 business days. Reviewers see the real values so they can decide accurately.
  5. Approved versions only. Users see the last approved version of each layer; an edit never takes a working layer offline.
  6. Weekly re-checks of every connected app.

AI review

GeoVivé can use a model on Amazon Bedrock to review a layer's settings and a sample of its text values for personal information, offensive or misleading content, data-quality problems and signs of criminal, security or targeting risk. Controls:

  • Only text is sent: layer settings and up to 40 features' labels and shown values, each cut to 300 characters. Shapes are never sent.
  • Processing stays in US AWS regions, in GeoVivé's own AWS account. AWS does not use Bedrock inputs to train models, and Bedrock request logging is turned off, so prompts and answers aren't stored.
  • The model is instructed to treat your data as untrusted and never follow instructions inside it.
  • AI findings never reject a layer on their own: they either add a note for you or send the layer to a person.
  • Only one model is permitted, reviews are capped per day, and AI review can be switched off at any time.

Logs and retention

  • Service logs are scrubbed before they're written: emails, phone numbers, street addresses, sign-in tokens, signed-link signatures and payment secrets are masked, and each entry is size-limited, so layer data and request bodies can't be logged whole. Logs are kept 30 days.
  • Check results store only where a problem is (for example “email address in Note”), not the value.
  • Layer versions waiting for human review, with a sample of values for the reviewer, are deleted after 90 days.
  • Evidence for possible criminal, security or targeting findings is kept encrypted in a separate restricted store for two years. The checking service can add to it but can't delete from it.
  • When an app disconnects, its display, relay and review copies are deleted at once; its reports and history are deleted 90 days later.
  • Reports and exports are delivered through short-lived signed links (10 minutes for reports).

Payments

Payments are handled by Stripe. GeoVivé never sees or stores card details, and holds no Stripe account keys; it only receives Stripe's signed confirmation that a payment completed.

Reporting a problem

If you see a layer that exposes personal information or looks harmful, or you've found a security issue, email admin@geovive.link.
